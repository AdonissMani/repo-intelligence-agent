# customer-profile

    customer-profile is owned by Customer Platform in Core Platform. It provides customer profile, preferences, contact details, segmentation metadata.

    Important caveat: Owns contact data but not identity verification decisions.

    ## Runtime Dependencies
    - none

    ## Public APIs
    - `GET /v1/customers/{id}`
- `PATCH /v1/customers/{id}`
- `GET /v1/customers/{id}/preferences`
