# identity-core

    identity-core is owned by Identity Platform in Core Platform. It provides authentication, authorization, token issuance, service identity.

    Important caveat: README still calls the service auth-core in a few places after a rename.

    ## Runtime Dependencies
    - customer-profile
- notification-core

    ## Public APIs
    - `POST /v1/auth/token`
- `GET /v1/users/{id}`
- `POST /v1/authorization/check`
